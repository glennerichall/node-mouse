# Backlog transversal et explorations

Ces idées ne sont pas des autorisations d'implémenter: avant de commencer,
promouvoir l'élément en tâche planifiée dans l'axe propriétaire avec périmètre,
dépendances et critères d'acceptation.

## Fonctions

- Multi-écrans, profils de commandes, retour haptique et personnalisation par appareil.
- Presse-papiers bidirectionnel avec consentement explicite.
- Macros limitées aux actions autorisées.
- Wake-on-LAN lorsqu'un agent local peut émettre le paquet.

## Explorations

- API de plugins, prévisualisation vidéo WebRTC, découverte mDNS.
- Gestion centralisée optionnelle de serveurs on-premise.
- Paquets natifs et signatures simplifiant l'octroi de permissions.
