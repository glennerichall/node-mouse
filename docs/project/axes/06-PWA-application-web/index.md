# 06 — PWA — Application web et modes de déploiement

## Résultat visé

Faire de Remote Mouse une télécommande web installable, fiable sur réseau local
ou distant, et sécurisée avant toute exposition à Internet. Le serveur local
historique reste disponible sans dépendre d'un service Internet.
