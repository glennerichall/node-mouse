# OPS-008 — Idempotence et mode non interactif

- La configuration ajoute les valeurs absentes, préserve les réglages et
  secrets existants, et les installations de service peuvent être rejouées.
- La documentation et l'aide CLI décrivent les options `setup`, la sélection
  du répertoire/port, et le comportement des prompts sans TTY. `--yes` n'accorde
  pas l'accès privilégié à uinput; `--no-service` reste prioritaire.
- Tests : `npm run test:install` — 24 tests réussis; `git diff --check` réussi.
- Aucun bump de version : changement opérationnel/documentaire, sans
  préparation de publication.
