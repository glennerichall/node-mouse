# Code — CODE-008 — 2026-10-09

État: terminé

## Objectif et critères d'acceptation

Nettoyer les scripts du dépôt et les commandes npm en retirant les alias
redondants, en renommant les entrées dont le nom ne décrit plus le rôle et en
conservant les scripts nécessaires à des parcours actifs.

## Décisions et raisons

- `npm start` est l'unique entrée de lancement; `npm run dev` ne faisait que
  répéter la même commande.
- `test:remote` est l'entrée canonique pour le profil d'intégration par défaut;
  `test:integration` ne faisait que lui déléguer.
- Le hook Linux ne compile plus; `postinstall-linux.mjs` décrit son contrôle des
  artefacts et la migration uinput plus fidèlement que son ancien nom `build-*`.
- Les scripts de build, installateurs, déploiement, versions, captures et commit
  gardent des appels actifs et sont conservés.

## Modifications apportées

- Suppression des alias `dev` et `test:integration` du manifeste npm; mise à
  jour de `test:all` pour appeler directement `test:remote`.
- Renommage de `build-native-input-if-available.mjs` en
  `postinstall-linux.mjs`, avec renommage de son export et mise à jour du test.
- Patch version porté à `6.19.77`.

## Vérifications et résultats

- Les références d'exécution et de documentation ont été recherchées; aucune
  utilisation active des alias supprimés ni de l'ancien nom du hook ne subsiste.
- `npm run check:version` réussit.
- Suites ciblées installateur et artefacts natifs: 4 suites, 23 tests réussis.

## Blocages / risques / suite

Aucun pour le nettoyage des scripts. La validation complète reste distincte des
tests ciblés de cette itération.
