# Architecture — ARCH-029 — 2026-10-07
État: terminé

## Objectif et critères d'acceptation

Réduire les routeurs HTTP à leur rôle de composition Express et rendre leurs
traitements réutilisables et testables indépendamment.

## Décisions et raisons

Les fonctions de sessions, souscriptions, état des remotes et API client sont
placées dans `connection/api/handlers`. Les routeurs ne font désormais que
déclarer les chemins, verbes et handlers associés.

## Modifications apportées

- Ajout de `admin-sessions.handlers.js`, `admin-subs.handlers.js`,
  `remotes.handlers.js` et `client-api.handlers.js`.
- Simplification des routeurs correspondants.
- Déplacement des imports de tests vers les handlers et ajout de tests pour
  les souscriptions administrateur et l'état des remotes.
- Version patch portée à `6.19.28`.

## Vérifications et résultats

- Tests ciblés : 3 suites, 12 tests réussis.
- `npm test -- --runInBand` : 108 suites, 367 tests réussis.
- `npm run check:version` : réussi.
- `git diff --check` : réussi.

## Blocages / risques / suite

Aucun blocage. Les contrats HTTP et les montages Express sont conservés.
