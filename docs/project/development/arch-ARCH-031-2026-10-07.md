Verrouiller les frontières de montage HTTP après le regroupement des routeurs,
afin que les prochains changements ne déplacent pas accidentellement les
préfixes publics ou protégés.

des routeurs marqueurs. Les tests vérifient les chemins exposés sans coupler
les tests de composition à l'implémentation des handlers métier.
