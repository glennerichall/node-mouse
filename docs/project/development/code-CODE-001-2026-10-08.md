# Qualité du code — CODE-001/002/005/006 — 2026-10-08

État: terminé

## Objectif et critères d'acceptation

Établir une convention de qualité mesurée, la vérifier automatiquement et
appliquer la passe sûre aux routeurs et fichiers concernés sans modification
fonctionnelle.

## Décisions et raisons

- Les zones du dépôt conservent leurs indentations historiques cohérentes :
  quatre espaces côté serveur et tests, deux espaces côté client et scripts.
- Le contrôle automatisé reste volontairement minimal : espaces finaux et
  tabulations sont des écarts objectifs, contrairement aux règles de
  formatage qui nécessiteraient un reformatage global.
- Les routeurs Express étaient déjà composés de handlers dédiés; la passe a
  confirmé ce contrat et normalisé les routeurs d'actions sans les réécrire.

## Modifications apportées

- Ajout de `scripts/check-code-style.mjs` et de `npm run check:style`.
- Intégration du contrôle de style à `npm test`.
- Suppression des espaces finaux détectés dans huit fichiers.
- Uniformisation des littéraux de chemins dans les routeurs d'actions.
- Documentation de la convention dans l'axe CODE.

## Vérifications et résultats

- `npm run check:style` : 453 modules validés.
- `npm test -- --runInBand --silent` : 111 suites et 382 tests réussis.
- `git diff --check` réussi.

## Blocages / risques / suite

Les tâches CODE-003 et CODE-004 restent ouvertes : elles concernent les
conventions de nommage/imports et une uniformisation stylistique plus large.
Elles feront l'objet de la prochaine itération contrôlée.
