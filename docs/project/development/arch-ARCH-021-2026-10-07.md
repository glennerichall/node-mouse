# Architecture — ARCH-021 — 2026-10-07
État: terminé

## Objectif et critères d'acceptation

Rendre testable le contexte de configuration partagé par les routes
administrateur sans dépendre du montage Express.

## Décisions et raisons

`getManagedContext` mélangeait la disponibilité VLC, la projection des valeurs
et la composition du routeur. Il est extrait sous le nom
`getManagedConfigContext`, avec un contrat d'entrée limité au conteneur de
services et un résultat stable pour les handlers.

## Modifications apportées

- Ajout de `getManagedConfigContext.js`.
- Remplacement des appels internes du routeur par le module dédié.
- Lecture unique de `services.getConfig()` par construction.
- Tests unitaires des cas VLC disponible et indisponible.
- Version patch portée à `6.19.20`.

## Vérifications et résultats

- Tests ciblés : 2 suites, 8 tests réussis.
- `npm test -- --runInBand` : 103 suites, 352 tests réussis.
- `npm run check:version` : réussi.
- `git diff --check` : réussi.

## Blocages / risques / suite

Aucun blocage. Les prochains contextes de routeur peuvent suivre le même
modèle d'extraction lorsqu'ils portent une logique de projection propre.
