# Architecture — ARCH-046 — 2026-10-08

État: terminé

## Objectif et critères d'acceptation

Clôturer la migration des messages d'actions vers le protocole générique
`route:request` et vérifier que les routeurs peuvent être réutilisés par un
transport HTTP Express, sans dépendre de Socket.IO.

Les critères ARCH-046 sont satisfaits : les actions sont exposées par des
routeurs `*.router.js`, le paquet transporte `{path, method, body}`, les guards
lisent ce paquet et les routeurs restent montables sur une application
Express.

## Décisions et raisons

- Le routeur d'actions conserve le contrat Express (`request`, `response`,
  `next`) afin que Socket.IO et HTTP partagent la même frontière.
- Les tests HTTP utilisent un montage Express en mémoire; aucun serveur réseau
  réel n'est requis pour valider le contrat de transport.
- La validation des domaines et méthodes reste à la frontière Socket.IO, tandis
  que la résolution des routes HTTP est laissée au routeur Express.

## Modifications apportées

- Ajout de `test/unit/action-routers.http.test.js` couvrant les neuf domaines

- Vérification du montage de `socketRouter` sous une application Express avec

- Mise à jour de la checklist ARCH-046 et conservation des décisions dans cet
