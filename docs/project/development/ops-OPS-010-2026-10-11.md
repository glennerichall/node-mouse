# OPS-010 — retour arrière des mises à jour

Les mises à jour npm automatiques vérifient et conservent, avant activation,
une archive SHA-512 de la version actuellement installée dans
`CONFIG_DIR/update-rollback`. Une seule archive précédente est gardée. Si
l'activation candidate échoue, le paquet sauvegardé est réinstallé; le CLI
local expose aussi `remote-mouse service rollback-update` pour demander un
retour arrière et redémarrer le service.

Le retour arrière ne touche qu'au paquet applicatif. Il ne restaure ni ne
remplace `.env`, la configuration persistée ou la base locale. Les
`UPDATE_INSTALL_COMMAND` personnalisées restent hors du snapshot automatique.
Le snapshot est vérifié depuis le même registre HTTPS configuré avant d'être
enregistré et son intégrité est revérifiée avant toute restauration.
