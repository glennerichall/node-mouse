# Architecture — ARCH-024 — 2026-10-07
État: terminé

## Objectif et critères d'acceptation

Extraire la logique de construction du catalogue des remotes hors du routeur
administrateur et la rendre testable indépendamment d'Express.

## Décisions et raisons

La disponibilité VLC et les règles d'activation navigateur sont des règles de
présentation métier, pas des responsabilités de composition de route. Elles
sont regroupées dans un module de handlers dédié.

## Modifications apportées

- Ajout de `admin-remotes.handlers.js` avec `isBrowserEnabled`, `listBrowsers`
  et `listRemotes`.
- Routeur réduit aux deux déclarations de routes.
- Export direct sous `adminRemotesRouter`; les consommateurs client et admin
  utilisent le même nom sans alias historique.
- Tests unitaires ajoutés pour les flags navigateur et l'inclusion conditionnelle
  de VLC.
- Version patch portée à `6.19.23`.

## Vérifications et résultats

- Test ciblé : 1 suite, 3 tests réussis.
- `npm test -- --runInBand` : 106 suites, 362 tests réussis.
- `npm run check:version` : réussi.
- `git diff --check` : réussi.

## Blocages / risques / suite

Aucun blocage. Les routeurs d'authentification et de sessions disposent déjà
de handlers exportés et pourront être harmonisés ultérieurement si nécessaire.
