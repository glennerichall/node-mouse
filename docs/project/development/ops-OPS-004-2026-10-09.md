# Exploitation — OPS-004 — 2026-10-09

État: terminé

## Objectif et critères d'acceptation

Rendre vérifiable quelle installation est réellement lancée et comparer la
version locale, la version candidate et le résultat après installation depuis
l'interface d'administration.

## Décisions

- Le démarrage relit le `package.json` depuis le chemin d'installation effectif
  et journalise aussi le chemin et l'exécutable Node, afin de repérer plusieurs
  installations ou préfixes npm divergents.
- Les vérifications npm retournent `currentVersion` et `latestVersion`, même
  lorsqu'aucune mise à jour n'est disponible. Le gestionnaire journalise aussi
  la version lue du paquet en cours d'exécution.
- L'installation journalise les versions avant, cible et après la commande. La
  version après installation est relue depuis le fichier du paquet sur disque;
  la version au prochain démarrage reste l'autorité pour le code effectivement
  rechargé.

## Modifications apportées

- Ajout des champs version, chemin du paquet et exécutable Node au journal de
  démarrage du serveur.
- Ajout des versions installée/comparée/candidate aux traces de vérification.
- Ajout des versions avant/cible/relue après à la trace d'installation, en cas
  de succès comme d'échec.
- Ajout de tests unitaires de la source npm, du gestionnaire d'installation et
  du journal de démarrage.

## Vérifications et résultats

- Suite Jest complète: 117 suites, 406 tests réussis.

`installedVersion`/`latestVersion` de la vérification et
