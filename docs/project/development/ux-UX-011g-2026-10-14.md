# UX-011g — isolation du seuil et dépassement directionnel

## Décision

Pendant la calibration d'un seuil, la remote reçoit quatre gains identiques au
gain du seuil courant. Le résultat du test ne dépend donc plus de
l'interpolation avec les trois autres seuils. Lorsque tous les seuils sont
stabilisés, la courbe complète des quatre gains est réappliquée.

Le dépassement est calculé avec les deltas ajustés : chaque delta est projeté
sur la direction A→B, les projections positives sont cumulées, puis comparées
à la distance directe entre les cibles. Le gain baisse lorsque cette progression
cumulée dépasse la distance cible.
