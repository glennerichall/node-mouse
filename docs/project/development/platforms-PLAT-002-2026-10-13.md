# PLAT-002 — parcours Windows validé

## Résultat

Le runner Windows GitHub Actions valide l'installation depuis le tarball npm,
la création et l'exécution de la tâche planifiée, la santé HTTP, la version et
les commandes CLI, la réinstallation du paquet avec conservation de la
configuration et de la base SQLite, puis la désinstallation complète du
service.

Les critères `PLAT-002`, `PLAT-002c`, `PLAT-002d`, `PLAT-002e` et `PLAT-002f`
sont clôturés.
