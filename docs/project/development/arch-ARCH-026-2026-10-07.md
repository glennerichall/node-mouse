# Architecture — ARCH-026 — 2026-10-07
État: terminé

## Objectif et critères d'acceptation

Extraire les handlers de page et de données serveur hors du routeur afin de
conserver une composition HTTP minimale.

## Décisions et raisons

La route `/data` regroupait collecte de services, redaction, tokens, journaux
et état système. Ces responsabilités sont déplacées dans un module de
handlers, tandis que les fonctions pures restent exportées par le routeur via
`__testables` pour compatibilité de tests.

## Modifications apportées

- Ajout de `server-info.handlers.js` avec `getServerInfoPage` et
  `getServerInfoData`.
- Routeur réduit aux deux routes et aux exports de test historiques.
- Tests directs des handlers page et data.
- Version patch portée à `6.19.25`.

## Vérifications et résultats

- Tests ciblés : 2 suites, 7 tests réussis.
- `npm test -- --runInBand` : 107 suites, 364 tests réussis.
- `npm run check:version` : réussi.
- `git diff --check` : réussi.

## Blocages / risques / suite

Aucun blocage. Le contrat JSON de la page d'information est inchangé.
